## 先弄清"这个项目是谁的"

- 产品负责人是**神朱**(甲壳神朱),中文沟通,**不写代码**。技术选型、实现方案都由 Agent 决定,他负责拍板与验收。
- 他的偏好:先用最小工程量出可跑的 DEMO,稳定后再升级;重要方案先出文档给他看;需要他做选择时**给可点选的选项**,不要开放式提问。
- 他技术记忆很好,会挑战"过时的结论"。所以引用历史故障的归因前,**先核对当时的配置今天是否还生效**(真有翻车案例:旧结论是"上下文窗口装不下前端",实际是配置文件把窗口手动设成了 64K)。

## 三条铁律

1. **只 commit 不 push**。推远端要单独获得授权(这个项目历史上 push 出过事故,所以规则很硬)。
2. **不代订、不抓实时价**。这是个目的地发现工具,价格一律标"估算",预订一律跳官方渠道。任何把它做成"直接下单"的改动都是越界。
3. **不新增第三方依赖**。测试全 mock、不触网,`pytest` 必须能在没有网络和没有 API key 的机器上全绿。

## 项目一年不到的简史(帮你看懂为什么代码长这样)

2026-09 立项,从 POC(命令行查 Overpass)一路做到当前形态。关键转折:

- **09 月中**:阶段 0~3 完成,地图模式 + 环形距离分段 + 住宿 + 收藏/行程方案。
- **10-01**:数据源**全面切高德**(POI/地理编码/驾车/前端地图),Overpass 与 OSRM 从主线移除。
- **10-10 ~ 10-12**:神朱报"搜国外目的地全部定位错",确诊高德只服务境内 → 做**境内外双轨**:境外复活 Overpass/OSRM + Leaflet 第二套地图引擎。
- **10-15 ~ 10-16**:容器化(Docker + `/setup` 向导 + GHCR 流水线 + release UI 模式),打完 `v0.1.0-beta`。
- **10-18 ~ 10-19**:修境外中文城市名定位 bug(TASK-27),发 `v0.2.0-beta`。

代码因此有三层历史痕迹:OSM 时代的残留、高德切过来的兼容层、境外双轨的分支。`03-pitfalls.md` 解释了哪些坑是历史包袱、哪些是真 bug。
