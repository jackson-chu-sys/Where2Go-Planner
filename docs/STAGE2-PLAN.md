## 2. 数据源与估算口径(诚实标注)

| 方式 | 时间 | 费用 | 数据性质 |
|---|---|---|---|
| 驾车 | OSRM 真实(含 geometry 画线) | **估算**:油费 + 过路费 | 时间真实、费用估算 |
| 铁路 | 估算(直线×绕行/均速 + 接驳) | **估算**:里程 × 单价 | 全估算,无实时班次 |
| 飞机 | 估算(直线×绕行/巡航 + 值机接驳) | **估算**:里程 × 单价 + 基建燃油 | 全估算,无实时票价 |

费用系数(可调常量,页面标注「估算」):
- 驾车:油耗 8 L/100km × 油价 7.5 元/L + 高速占比(默认 0.7) × 里程 × 0.5 元/km
- 铁路(二等座):里程 × 0.45 元/km,设起步价下限
- 飞机(经济舱):里程 × 0.6 元/km + 100 元(机建+燃油)

> **合规**:仍不抓 OTA/12306 实时价,只做信息聚合 + deep-link 跳转(ADR-004/ADR-007)。所有价格页明确「估算 · 非实时 · 以官方为准」。

## 3. 前端交互(Leaflet)

1. 地图点某目的地 pin → 侧栏/弹层出**路线面板**:三种方式卡片(图标 + 时长 + 费用 + 一行说明)。
2. 选中方式 → 地图上**画该路线**(驾车用 OSRM geometry 折线;铁路/飞机为示意直线或大圆)。
3. 每个方式卡片带**跳转按钮**:驾车→高德/Google 导航 URL;铁路→12306 查询 URL;飞机→OTA 搜索 URL(外部 deep-link,新页)。
4. 「收藏路线」按钮(落 Collection 表)。
5. 时效标注:每条路线带「生成时间 + 数据来源 + 估算/真实」标识。

## 6. 风险

1. **费用为估算**:用户可能误当真实票价 → 页面强标注「估算」+ 跳转官方核对。
2. **公交/大巴方式缺失**:免费源无班次数据 → 本阶段不做,归入「复合路线」后续。
3. **OSRM geometry 体积**:长路线折线点多 → 前端简化(抽稀)后再画。
4. **合规**:仅 deep-link,不代订、不抓价。
