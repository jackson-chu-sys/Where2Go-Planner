## 1. M3 住宿信息 + AI 预估参考价

**口径(沿用既有拍板)**:现阶段**只用 AI 预估参考价**,不抓 OTA 实时价(无免费官方接口 + 合规)。页面强标注「AI 预估 · 仅供参考 · 以 OTA 实时为准」。

| 组件 | 说明 |
|---|---|
| 住宿检索 | OSM `tourism=hotel/guest_house/hostel/apartment/chalet` 按目的地周边半径检索(复用 Overpass 端点链) |
| 预估价 | LLM 依 名称/类型/位置/OSM 标签 给**参考价区间**(如「约 ¥300-500/晚」),按住宿缓存到 DB |
| 数据模型 | `Stay` 表(id, osm_id, name, kind, lat, lng, place_id, price_estimate, currency, intro, fetched_at) 或复用 Place 加 type |
| API | `GET /api/stays?place_id=|lat=&lng=&radius=` 返回住宿列表(名称/类型/距离/预估参考价/简介) |
| 收藏 | 复用 TASK-2c 的 Collection(post type=stay) |

## 2. M4 收藏对比 + 跳转预订

| 组件 | 说明 |
|---|---|
| 统一收藏面板 | 汇总收藏的 目的地/路线/住宿;对比展示 路线时长、路线费用、住宿费用 |
| 行程方案组合 | 「某目的地 + 某路线 + 某住宿」组合为一个方案,给大致总花费 |
| 预订界面 | 列出可用/已收藏的路线与住宿,勾选组合 |
| 跳转预订 | deep-link 跳 携程/Booking/12306/地图 App(不代订,仅跳转) |
| 免责 | 明确「价格仅供参考 · 本应用不代订 · 仅信息聚合与跳转」 |
